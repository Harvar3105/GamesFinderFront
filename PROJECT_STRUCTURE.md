# GamesFinderFront project structure

Frontend of GamesFinder, a service that collects digital product (game) offers from several sources.

- **Stack:** Next.js 16 (App Router, React Compiler), React 19, TypeScript, Tailwind CSS v4, TanStack Query, axios (server only), Redis (sessions).
- **Architecture:** BFF (Backend for Frontend). The browser only calls Next.js routes in `src/app/api`. On the server, those routes call the Identity service and the backend, and keep sessions in Redis.
- **Design:** the «GamesFinderDesign» design system and the «GamesFinder — макеты страниц» page mockups (claude.ai artifacts).

## Repository root

| file / folder | purpose |
| --- | --- |
| `src/` | source code (described below) |
| `public/` | static files served as is: `favicon.ico`, `pfp.jpg` (default avatar) |
| `next.config.ts` | Next.js config: React Compiler, allowed image domains (Steam CDN) |
| `tsconfig.json` | TypeScript, aliases `@/app/*`, `@/assets/*`, `@/components/*`, `@/domain/*`, `@/lib/*` |
| `postcss.config.mjs` | Tailwind v4 via `@tailwindcss/postcss` |
| `eslint.config.mjs`, `prettier.config.js` | linting and formatting |
| `.env.local`, `.env.prod` | environment variables: Identity, backend and Redis addresses (not in git) |
| `AGENTS.md`, `CLAUDE.md` | rules for AI agents (the Next.js block is generated by `next dev`) |

## `src/app` — pages and BFF routes

App Router file-based routing. Each folder is a URL segment, `page.tsx` is a page. Folders in parentheses, such as `(auth)`, are route groups and do not appear in the URL.

| path | URL | purpose |
| --- | --- | --- |
| `layout.tsx` | — | root layout: `<html data-theme>`, fonts, providers, header, footer. The theme is read from the `theme` cookie on the server |
| `fonts.ts` | — | fonts via `next/font/google`: Fira Sans, Doto, Google Sans Code |
| `globals.css` | — | design tokens (theme colors, spacing per window class, radii, shadow, text styles), their Tailwind mapping (`@theme`), `typo-*` utilities, base styles |
| `page.tsx` | `/` | home page |
| `(auth)/login/page.tsx` | `/login` | sign in |
| `(auth)/registration/page.tsx` | `/registration` | sign up |
| `api/(auth)/login/route.ts` | `POST /api/login` | BFF: sign in via Identity, create a Redis session, set the cookie |
| `api/(auth)/registration/route.ts` | `POST /api/registration` | BFF: sign up |
| `api/(auth)/logout/route.ts` | `POST /api/logout` | BFF: sign out, delete the session |

Pages from the mockups that are not in the code yet: catalog (`/catalog`), product (`/catalog/[id]`), account (`/account`), administration (`/admin`).

## `src/assets` — embedded media

Images, fonts and other files imported in code and processed by the build (unlike `public/`).

Empty for now. The logo in the new design is text set in Doto.

## `src/components` — reusable components

| folder | contents |
| --- | --- |
| `ui/` | base design-system components, imported from `@/components/ui`: `Button` / `ButtonLink`, `IconButton` / `IconLink`, `Icon`, `Panel`, `Field` / `Input` / `Select` / `Checkbox`, `Chip` / `ChipToggle`, `Badge`, `Avatar` (takes a `UserDTO`), `Thumb`, `Table` / `TableHeader` / `TableCell` |
| `helpers/` | small helpers for components: `mergeClassNames` |
| `layouts/` | layout parts: `header.tsx`, `footer.tsx` |
| `providers/` | React contexts: `theme/` (theme and switcher), `userProvider.tsx` (current user), `queryProvider.tsx` (TanStack Query) |
| `widgets/` | composite blocks with logic: `loginWidget.tsx` (sign in / user block in the header) |

Components from the mockups are added here during the redesign: buttons, inputs, panels, chips, tables, icons and so on.

## `src/domain` — BFF contracts and entities

Types shared by the client and the server. No side effects.

| path | purpose |
| --- | --- |
| `contracts/in/` | what the browser sends to the BFF (`LoginPayload`, `RegistrationPayload`) |
| `contracts/out/` | what the BFF sends to and receives from external services (`LoginRequest`, `IdentityAuthModel`, `SessionTokens`) |
| `entities/` | entities: `Entity` (base: id, dates), `User`, `UserData`, `UserDTO`; `enums/ETheme` (`light` / `dark`) |
| `navPages.tsx` | page URLs for navigation |

## `src/lib` — helpers and the server side of the BFF

| path | purpose |
| --- | --- |
| `config.ts` | reads environment variables (server only) |
| `toQueryString.ts` | object → `URLSearchParams` |
| `client/fetch/bffFetch.ts` | client `fetch` to BFF routes with error handling (`FetchError`) |
| `server/apiClient.ts` | base axios client for external services |
| `server/auth/authClient.ts` | Identity client: sign up, sign in, tokens |
| `server/auth/logger.ts`, `withLogging.ts` | BFF request logging |
| `server/redisClient.ts` | Redis connection |

## Styles (Tailwind v4)

Tailwind's default colors, radii, shadows, fonts and breakpoints are disabled: only design tokens are available.

| what | utilities |
| --- | --- |
| colors | `bg-background`, `bg-container`, `bg-component`, `bg-element`, `bg-primary`, `text-text`, `bg-component-hover`, `bg-row-hover` |
| spacing | `*-related-xs/sm/md/lg`, `*-attention-sm/md/lg`, `*-edge-x`, `*-edge-y` (values depend on the window width) |
| radii | `rounded-sm` 8px, `rounded-md` 12px, `rounded-full` |
| shadow | `shadow-container` |
| fonts | `font-sans`, `font-doto`, `font-code` |
| text styles | `typo-display`, `typo-h1`, `typo-h2`, `typo-logo`, `typo-logo-footer`, `typo-button`, `typo-label`, `typo-small`, `typo-caption`, `typo-price-lg`, `typo-badge`, `typo-code` |
| window classes | `medium:` ≥600, `expanded:` ≥840, `large:` ≥1200, `xlarge:` ≥1600 |
| themes | `dark:`, `light:` |

## Data flow

```text
Browser (page / component)
  └─ BFFFetch / useMutation ─► src/app/api/*/route.ts (Next.js server)
                                  ├─ lib/server/auth/authClient ─► Identity service
                                  ├─ lib/server/apiClient       ─► backend
                                  └─ lib/server/redisClient     ─► Redis (sessions)
```
